# Hospital Patient Data Analysis

## Project Overview
The Hospital Patient Data Analysis project is a Python-based data analytics project developed to clean, analyze, and visualize hospital patient data.

The project focuses on transforming raw hospital data into meaningful information using Python libraries and exploratory data analysis techniques.

## Objectives
- Clean and prepare hospital patient data for analysis
- Handle missing and duplicate values
- Identify and correct data quality issues
- Perform exploratory data analysis
- Analyze patient and hospital-related information
- Visualize patterns and relationships using charts

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning
The dataset was cleaned and prepared before performing the analysis.

The cleaning process includes:
- Checking and removing duplicate records
- Handling missing values
- Correcting data types
- Checking invalid values
- Cleaning text-based columns
- Preparing the dataset for analysis

## Exploratory Data Analysis
The project analyzes different areas of hospital patient data, including:
- Patient age
- Gender
- Department
- Disease / medical condition
- Doctor
- Insurance provider
- Payment-related information
- Hospital billing information

## Data Visualizations
Different charts are used to understand the data clearly, including:
- Histogram
- Box Plot
- Count Plot
- Bar Plot
- Scatter Plot
- Line Plot
